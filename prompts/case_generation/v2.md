# Prompt: case_generation v2

## Agent

CaseGenerationAgent

## Purpose

Generate reviewable test cases that remain traceable to the immutable claims
captured from the requirement, reviewed risks, and approved knowledge evidence.

## Input Schema

```json
{
  "type": "object",
  "required": ["requirement", "requirement_claim_snapshot", "target_test_types", "decision_table_acknowledged"],
  "properties": {
    "requirement": {"type": "string"},
    "requirement_claim_snapshot": {
      "type": "object",
      "required": ["version", "snapshot_hash", "claims"],
      "properties": {
        "version": {"const": "requirement-claims-v1"},
        "snapshot_hash": {"type": "string"},
        "claims": {"type": "array"}
      }
    },
    "requirement_review": {"type": ["object", "null"]},
    "risk_items": {"type": "array"},
    "target_test_types": {"type": "array", "items": {"type": "string"}},
    "decision_table_acknowledged": {"type": "boolean"},
    "decision_table_dimensions": {"type": "array"},
    "knowledge_evidence": {"type": "array"},
    "context_artifact_ids": {"type": "array", "items": {"type": "string"}},
    "context_manifest": {"type": "array"}
  }
}
```

## Output Schema

```json
{
  "type": "object",
  "required": ["cases", "used_context_artifact_ids"],
  "properties": {
    "cases": {
      "type": "array",
      "minItems": 1,
      "items": {
        "type": "object",
        "required": ["title", "priority", "test_type", "steps", "expected_results", "requirement_refs", "risk_refs", "coverage_claims", "coverage_dimensions", "ai_reason"],
        "properties": {
          "coverage_claims": {
            "type": "array",
            "minItems": 1,
            "items": {
              "type": "object",
              "required": ["claim_id", "evidence"],
              "properties": {
                "claim_id": {"type": "string"},
                "evidence": {"type": "string", "minLength": 1}
              }
            }
          }
        }
      }
    },
    "used_context_artifact_ids": {"type": "array", "items": {"type": "string"}}
  }
}
```

## Instructions

Return JSON only. Do not include markdown fences.
Use only claims from `requirement_claim_snapshot`; never create a claim id.
Every case must cite one or more claims in `coverage_claims`. Copy a short,
specific supporting excerpt from the cited claim into `evidence`, and make the
case steps and expected results test that same behavior.
For a risk claim, also put the risk id from its `source_ref` into `risk_refs`.
For a knowledge-evidence claim, also include that evidence item in
`source_knowledge_evidence`.
Do not invent permissions, boundaries, retries, failure behavior, or business
rules that are absent from cited claims. Omit unsupported scenarios and report
the omission in `coverage_gap_notes` when useful.
Generate review candidates only. Each case needs concrete steps, observable
expected results, a supported coverage dimension, and an AI reason.

## Failure Output

```json
{
  "error_code": "UNABLE_TO_GENERATE_GROUNDED_CASES",
  "message": "No immutable requirement or risk claim can support a useful test case.",
  "recoverable": true
}
```
