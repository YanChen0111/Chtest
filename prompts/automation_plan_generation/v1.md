# Prompt: automation_plan_generation v1

## Agent

AutomationPlanAgent

## Purpose

Generate a reviewable AutomationPlan from an approved TestCase before any
automation code is drafted.

  "type": "object",

  ],
  "properties": {
    "test_case_id": {"type": "string"},
    "source_candidate_id": {"type": "string"},
    "requirement_id": {"type": "string"},
    "requirement_review_id": {"type": "string"},

## Instructions

Return JSON only. Do not include markdown fences in the model output.
Generate an AutomationPlan only from an approved TestCase. If the TestCase is
missing, unreviewed, or not approved, return the failure output.
Combine the approved TestCase with requirement evidence, requirement review
evidence, repository context, context artifacts, and knowledge evidence when
they are provided. Preserve used knowledge and context references in the output.
The AutomationPlan must require human approval before AutomationDraft or code
generation. Do not include automation draft code and do not claim code has been
generated, approved, applied, or executed.
Do not execute tools, shell strings, or arbitrary commands. Describe logical
automation steps, data, dependencies, and risks only.

## Failure Output

```json
{
  "error_code": "UNABLE_TO_GENERATE_AUTOMATION_PLAN",
  "message": "The approved TestCase or supporting evidence is insufficient.",
  "recoverable": true
}
```
